How to Fix Issues

# If tests fail, try these steps: 1. Hard Refresh Browser: - Windows/Linux: Ctrl + Shift + R - Mac: Cmd + Shift + R 2. Clear Browser Cache: - Chrome: F12 → Network tab → Disable cache checkbox - Or use the "Clear Cache" button above 3. Check Console for Errors: - Press F12 - Go to Console tab - Look for red error messages 4. Verify Files Are Updated: - Check booking-flow.js has validatePhone() function - Check mpesa.js has updated toast messages - Check HTML files have new placeholders
